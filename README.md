# Machine Failure Prediction Project

## Overview
This project predicts machine failure using sensor data. It includes data exploration, preprocessing, and machine learning modeling.

## What’s Done
- Data loading and cleaning
- Exploratory data analysis
- Target variable inspection
- Feature correlation analysis
- Initial visualizations

## What’s Next
- Handle class imbalance
- Feature engineering
- Model training and evaluation

## Dataset
Dataset contains 10,000 rows with features like Air temperature, Process temperature, Torque, Rotational speed, Tool wear, and Machine failure.
